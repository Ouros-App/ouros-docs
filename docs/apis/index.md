# APIs

Esta seção deve explicar como **consumir** as APIs do Ouros e quando usar cada serviço.

Para cada API, prefira documentar:

1. responsabilidade do serviço;
2. URL por ambiente;
3. autenticação necessária;
4. principais recursos;
5. exemplos de request e response;
6. erros comuns;
7. link para Swagger/OpenAPI quando disponível.

!!! tip
    Evite copiar manualmente dezenas de endpoints do Swagger. Use esta documentação para explicar contexto, fluxos e exemplos que não ficam claros apenas pela especificação OpenAPI.
