# Ouros Docs

Esta é a documentação técnica central da plataforma Ouros.

O objetivo deste portal é explicar **como os serviços se conectam, como usar as APIs e como desenvolver no ecossistema Ouros** sem espalhar conhecimento importante por vários READMEs.

!!! note "Regra simples"
    O README de cada repositório explica **aquele repositório**. Este portal explica **o sistema Ouros**.

## Por onde começar

- [Começando](getting-started/index.md): entrada para quem acabou de chegar ao projeto.
- [Arquitetura](architecture/index.md): serviços, responsabilidades e fluxos.
- [APIs](apis/index.md): como consumir e integrar as APIs.
- [Bancos de dados](databases/index.md): bancos, responsabilidades e fluxo de dados.
- [Segurança](security/index.md): autenticação, autorização e secrets.
- [Desenvolvimento](development/index.md): padrões e fluxo de contribuição.
