# Segurança

Centralize aqui a documentação de segurança que desenvolvedores precisam conhecer para trabalhar no Ouros.

## Conteúdo sugerido

- autenticação e emissão de tokens;
- autorização;
- Keycloak;
- service accounts;
- gerenciamento de secrets;
- Infisical;
- regras para ambientes;
- práticas para logs e dados sensíveis.

!!! warning
    Documente **como configurar e usar secrets**, mas nunca coloque o valor real de um secret no repositório.
